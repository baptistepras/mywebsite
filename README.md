# baptistepras.fr

Source of my personal website: https://baptistepras.fr

A static site in HTML and JavaScript, hosted on GitHub Pages. It presents my research, publications and projects, and runs the Kawa interpreter in the browser (compiled to JavaScript in `kawai.bc.js`).

To view it locally:

```bash
python3 -m http.server
```

then open http://localhost:8000.
